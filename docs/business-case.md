## 0. 핵심 결론 (먼저)

1. **이 사업의 본질은 "수익화 사업"이 아니라 "유입(바이럴) 사업"이다.** 결제율 2~5%·ARPPU $4~6이라는 얇은 단가 구조에서, 수익은 전적으로 **DAU 규모**의 함수다. 따라서 사업성의 90%는 *콘텐츠가 바이럴되는가(K-factor)* 한 가지에 달려 있고, 가격·페이월 설계는 나머지 10%다.
2. **전략 갈림길이 사업성을 가른다.**
   - **A. 국내 통스통스**(자기발견 테스트/운세/카드뉴스): 손익분기까지 **빠르고 자본효율적**(스폰서 콘텐츠 고마진 + 운세 IAP가 국내 검증됨), 단 **천장이 낮고 해자가 약함**.
   - **B. 외국인 K-밈 피벗**(master-strategy 방향): **천장이 높음**(글로벌 TAM 2.25억), 단 **손익분기가 멀고**(얇은 ARPPU × 대규모 DAU 필요) 실행 리스크가 큼(모바일 핵심 루프 미구현, 인증 블로커).
3. **정량 결론(추정)**: 소규모 팀 번레이트를 월 **₩20~30M**로 보면, 손익분기는 대략 **순매출 $15~22K/월**. 이는 광고·언락 중심 모델에서 **~12~18K DAU** 구간에 해당. 즉 *1만 DAU를 안정적으로 넘기지 못하면 적자, 넘기면 흑자 전환 가시권*.
4. **가장 싼 검증이 가장 비싼 리스크를 죽인다.** 코드 투자(인증 재작성·결제 연동) 이전에, **무료 콘텐츠 10개 + TikTok 채널로 K-factor와 CAC를 먼저 측정**해야 한다. 바이럴이 안 나오면 이후 모든 수익화 수치는 0이 된다.
5. **추천(잠정)**: *Phase 0(콘텐츠/바이럴 검증)을 두 방향 공통으로 먼저 돌리고*, 검증 신호(유입 단가·리텐션·공유계수)를 보고 A/B를 확정. 코드·자본 투입은 그 게이트 통과 후.
6. **목표가 월 ₩200만 순수입(1인·라멘)인 경우(§5-3)**: 게임이 바뀐다 — *1만 DAU 불필요*, **~2천 DAU 또는 월 스폰서 1건**이면 도달. 이 목표엔 **A(국내)가 명확히 우위**이고, **고정비를 0에 가깝게(혼자·오가닉) 유지하는 것이 유일한 성공/실패 조건**.

> ⚠️ 이 초안의 모든 흑자/적자 판정은 **"바이럴 유입이 유료 CAC 없이 작동한다"**는 전제 위에 있다. 유료 UA로 DAU를 사야 한다면 단가 구조상 LTV<CAC가 되기 쉬워 사업성이 급격히 악화된다(§6 민감도).

## 4. 비용 구조 & 번레이트 (★ 기존 문서 누락분)

> 디지털 콘텐츠라 한계비용은 0에 수렴. 사업성을 가르는 건 **고정비(팀)** + **유입비(CAC)** + **생산비(큐레이션)**.

### 4-1. 월 고정/운영비 (추정)
| 항목 | 초기(~10K DAU) | 성장(~50K DAU) | 비고 |
|---|---|---|---|
| 인프라(Fly.io+Supabase+R2/CDN) | $300~800 | $2~3K | 이미지 CDN·DB. DAU 비례 |
| AI 콘텐츠 생산(API) | $100~300 | $300~800 | 초안 생성 |
| 콘텐츠 큐레이션/검수(인건) | ₩2~3M | ₩4~6M | 한국인 검수 필수(평판비용) |
| 개발/운영 인건 | ₩solo~3M | ₩6~12M | 핵심 루프·결제 유지보수 |
| 광고/UA(선택) | ~₩0 (오가닉) | 가변 | **유료 UA는 단가 구조상 위험(§6)** |
| 도구/SDK/스토어 | ~$100 | ~$300 | 광고 SDK·분석 |
| **번레이트 합계(추정)** | **월 ₩6~10M (린 1~2인)** | **월 ₩20~30M (3~4인)** | |

### 4-2. CAC / LTV (추정)
- **LTV(글로벌 B)**: ARPPU $4~6 × 결제율 2.5% = *유료 LTV는 얇음*. 실질 LTV는 **광고 누적 + 공유 유입 가치**가 좌우 → "LTV ≈ 광고 ARPDAU × 잔존일수 + 결제 기여".
  - 예: ARPDAU $0.02 × 평균잔존 45일 ≈ **$0.9/유저** + 결제 기여 $0.1~0.3 ≈ **LTV $1.0~1.2** (보수적).
- **CAC**: 오가닉(TikTok 바이럴) = *콘텐츠 제작 시간*이 실질 비용, 현금 CAC ~$0. 유료 UA = 엔터 앱 설치 $0.5~2.
- **판정**: **LTV(~$1) < 유료 CAC($0.5~2)** 가 되기 쉬움 → **유료로 유저를 사면 적자.** ⇒ *오가닉 바이럴이 사업의 생명선이자 유일한 합리적 유입원*.

## 5. 손익분기 & 자본 소요

### 5-1. 손익분기 (BEP)
- 순매출 = 번레이트 지점.
- 린 1~2인(₩6~10M ≈ $4.5~7.5K/월): BEP ≈ **순매출 $5~7.5K** → 글로벌 모델 **~5~7K DAU** 또는 국내 모델 **스폰서 1~2건 + 소규모 DAU**.
- 소규모 팀(₩20~30M ≈ $15~22K/월): BEP ≈ **순매출 $15~22K** → 글로벌 모델 **~12~18K DAU**.
- **결론**: *1만 DAU 안정화*가 흑자/적자의 실무 분기선. 그 전엔 자본으로 버티는 구간.

### 5-2. 자본 소요(런웨이)
- Phase 0~1(검증 + MVP)까지 **6~9개월** 가정, 린 번레이트 ₩6~10M/월 → 필요자본 **₩40~90M** (인건 자가부담 시 인프라·생산비만이면 ₩300~800만/월로 훨씬 적음).
- 핵심: **흑자 전 구간의 길이 = 바이럴이 1만 DAU를 만드는 데 걸리는 시간.** 이게 6개월이면 소자본 가능, 18개월이면 외부자본 필요.

### 5-3. ★ 목표 시나리오: 월 ₩200만 순수입 (1인 / 라멘 프로피터빌리티)

> 전제: ₩2M/월 **순수입(take-home, 확인됨)**, **1인 자가개발**(인건비=본인 목표소득), **유료 UA 0(오가닉)**, 고정비 최소.

- 고정비(인프라+AI+도구) ≈ **월 ₩40~80만** + 세금/4대보험 버퍼(종합소득세 등) ≈ 목표의 ~10~20% → 필요 순매출 ≈ **₩300~340만/월(~$2,200~2,500)**. (세전 단순화 시 ₩260만)
- 환산: 광고/IAP 믹스 기준 위 필요 DAU에 ~15~20% 가산(약 1.8~3K DAU) 또는 스폰서 단가/건수로 흡수.
- "팀 BEP ~1만 DAU"와 **다른 게임** — 훨씬 작은 규모에서 성립.

| 도달 경로 | 필요 규모(추정) | 비고 |
|---|---|---|
| 광고만(국내 ARPDAU ₩20~40) | ~2.5~4K DAU | 볼륨 의존 |
| 운세 IAP만(₩2,900, 전환 3~5%) | ~2~5K DAU | 국내 WTP 검증 |
| **광고+IAP 믹스** | **~1.5~2.5K DAU** | **현실적 기본선** |
| **스폰서 1건/월(₩200~300만)** | **1건이면 목표 달성** | 오디언스(수천 MAU) 선행 |
| 글로벌(B) 광고+언락 | ~1.5K DAU | 단가 얇아 변동 큼 |

**판정**:
1. ₩200만은 **~2천 DAU 안정화** 또는 **월 스폰서 1건**이면 닿음. 1만 DAU 불필요.
2. 이 목표엔 **A(국내)가 명확히 우위** — 작은 오디언스 + 고마진 스폰서/운세 IAP로 도달, 실행 리스크·언어장벽 작고 코드베이스 정합.
3. **유일한 사망 조건 = 고정비 증가.** 1명 채용(₩300만) 시 목표가 ₩200만→₩500만+로 뛰고 필요 DAU 2배+. → *혼자·싸게·오가닉*이 절대 원칙.
4. 그래도 1순위는 **바이럴 검증**: 2천 DAU도 오가닉이 작동해야 모임(Phase 0 유효).

### 5-4. 갈림길별 자본효율 (정성 비교)
| | A. 국내 통스통스 | B. 외국인 K-밈 |
|---|---|---|
| 흑자까지 속도 | **빠름**(스폰서 고마진 + 운세 IAP 즉시) | 느림(스케일 의존) |
| 필요 DAU | 낮음(스폰서가 보완) | 높음(얇은 단가) |
| 천장 | 낮음 | **높음** |
| 해자 | 약함(언어·문화 장벽 없음) | **상대적 강함**(큐레이션·아카이브·브랜드) |
| 실행 리스크 | 낮음(자산 정합) | 높음(루프 미구현·인증 블로커·문화 오역) |
| 적합 전략 | 자본 적고 빠른 현금흐름 원할 때 | 큰 베팅·외부자본·고성장 노릴 때 |

## 6. 민감도 분석 (무엇이 사업성을 흔드나)

순매출 ≈ **DAU × 잔존 × (광고 ARPDAU + 결제율 × ARPPU/MAU환산 + 제휴)**. 지배 변수 순:

| 레버 | 영향 | 비고 |
|---|---|---|
| **① K-factor / 오가닉 유입** | ★★★★★ | <1이면 사업 자체 불성립. 모든 수치의 곱셈 인자 |
| **② DAU 스케일** | ★★★★★ | 얇은 단가의 유일한 보상. BEP의 직접 결정 |
| ③ 리텐션(잔존일수) | ★★★★ | LTV·광고 누적 직결. 콘텐츠 신선도 treadmill 리스크 |
| ④ 결제율 / ARPPU | ★★★ | 2.5%→4% 시 언락 매출 +60%, 그래도 광고만큼 못 떠받침 |
| ⑤ 스폰서 단가·건수(A모델) | ★★★★ | 국내 모델에선 ②를 부분 대체하는 고마진 점프 |
| ⑥ 유료 CAC 의존도 | ★★★★(−) | 유료 UA 비중↑ = LTV<CAC로 적자 가속 |

**스트레스 시나리오**
- **Bear**: K-factor<1, 오가닉 약함 → DAU 정체 → *어떤 수익화도 무의미*, 사업 중단/피벗.
- **Base**: 오가닉으로 10~20K DAU, 결제율 2.5% → 린 팀 흑자 가시권, 천천히 성장.
- **Bull**: 텐트폴 1건 바이럴 → 50K+ DAU, 스폰서·구독 본격 → 월 순매출 $69K+, 흑자·재투자.

## 9. 잠정 권고

1. **Phase 0를 두 방향 공통 검증으로 즉시 시작** (콘텐츠가 자산 재활용이라 추가비용 작음).
2. **흑자 임계 = ~1만 DAU**를 북극성 보조지표로. 그 전엔 *유입(바이럴)에만* 집중, 수익화는 훅만 심기.
3. **유료 UA 금지(검증 전)** — 단가 구조상 적자 함정.
4. **A(국내)로 빠른 현금흐름 vs B(글로벌)로 큰 베팅**은 실험 1 데이터로 결정. *현 코드베이스·운세 WTP는 A에, 시장 천장·해자는 B에 유리.*
5. **결제 전 JWKS 인증 수정**을 재무 리스크(사기·결제 차단) 차원에서 백로그 1순위 고정.

## 11. ★ 가장 빠른 출시 경로 (v0) — 웹뷰 서비스 우선

> 전제: **통스통스 = 웹뷰 서비스를 꽂는 플랫폼.** 첫 서비스는 플랫폼/앱과 분리된 *독립 웹 미니앱*으로 만들어 빠르게 출시·검증하고, 통으로는 나중에 편입.

### 11-1. 웹뷰 방식이 우회하는 블로커
서버를 *네이티브 앱 + 서버 결제* 경로로 띄우면 블로커(아래)가 있으나, 첫 서비스를 **독립 웹 미니앱**으로 내면 전부 우회됨:

| 블로커 | 네이티브+서버결제 경로 | **독립 웹뷰 경로(v0)** |
|---|---|---|
| 🔴 JWKS 인증 위조(`AuthService.swift`) | 결제 전 필수 수정 | 무로그인(생년월일 입력) → **서버 인증 안 탐** |
| ❌ 서버 결제/엔타이틀먼트(없음) | 신규 구현 + IAP 30% | 웹 결제(토스페이먼츠/카카오페이) → **수수료 0, 서버 불필요** |
| ❌ /share OG(없음) | ShareController 신규 | 웹앱 SSR 자체 메타태그 → **서버 안 거침** |
| 번들 서빙·카탈로그 | ✅ 완료(Supabase Storage) | v0엔 미사용, 편입 시 활용 |

### 11-2. v0 정의 (추천: 운세/사주 웹 미니앱)
- **무엇**: 생년월일·시 입력 → 무료 요약 운세 + **₩2,900 심층 리포트 페이월**(토스페이먼츠 웹 결제).
- **왜 운세**: 국내 WTP 검증(포스텔러·점신), AI로 해석 생성 빠름, 결과화면=결제슬롯 천연 궁합.
- **왜 웹 먼저**: 앱스토어 심사·IAP·JWKS 전부 우회, 카톡 링크로 즉시 배포. *앱 안 웹뷰의 웹결제는 스토어 정책 위반 소지 → 웹 먼저가 정석, 앱 통합은 검증 후.*
- **이 서버 역할**: v0엔 거의 없음. 검증 후 통으로 편입 시 카탈로그/공유에 등장.

### 11-3. v0 최소 빌드 (별도 웹 레포)
1. 웹 미니앱(Next.js SSR 권장 — OG 자체 처리): 입력 폼 → 결과.
2. **만세력 계산** — 검증된 라이브러리(음력·천간지지). ⚠️ *계산은 정확히, 해석만 AI 생성* (계산 틀리면 신뢰 붕괴).
3. 토스페이먼츠 웹 결제 + ₩2,900 페이월.
4. 결과 OG 공유 카드(카톡 미리보기) → K-factor.
5. 분석(GA/Posthog): 결제 전환율·공유계수 측정.

> v0의 목적은 매출이 아니라 **"운세 웹뷰가 카톡에서 퍼지고 ₩2,900을 내는가"** 검증. 통과하면 통으로 편입 + 다음 서비스 추가. 실패하면 다른 웹뷰 서비스로 저비용 교체.

### 11-4. 미해결(다음 단계로 미룸)
- 앱 통합 시 → JWKS 인증 수정 + 네이티브 IAP(또는 외부결제 정책 검토).
- 플랫폼 카탈로그/SDUI에 운세 통 노출 + 공유 통합.
