# 수익화 전략: 통스통스

**작성일**: 2026-06-05
**원칙**: 유저 먼저(무료+바이럴) → 수익화는 Phase 2. **단, 지금 "훅"만 심어 수익화-레디로.**
**전제**: 아래 단가/전환율은 런칭 전 추정(illustrative). 실제는 검증으로 확정.

---

## 0. 핵심 요약
- **베이스라인**: 광고(특히 **리워드 광고**) — 무료 캐주얼 콘텐츠의 기본
- **차별화 엔진**: **스폰서/브랜디드 콘텐츠** (통·카드뉴스 자체가 네이티브 광고) ← 이 제품의 진짜 수익 엔진
- **근거리 현금**: **운세/심층결과 IAP** — 국내 운세 WTP가 실재(포스텔러·점신류)
- **장기**: 창작자 마켓플레이스 정산

---

## 1. 광고 (Display · Native · **Rewarded**)
**작동**: 피드 사이 네이티브 광고 + 테스트→결과 사이 전면, 그리고 핵심은 **리워드 광고**(광고 보면 심층 결과 해금 / 대기 스킵 / 운세 1회 더).
**타깃 적합성**: 유저는 돈 안 냄(광고주가 지불) → WTP 마찰 0. 짧고 빈번한 세션이 노출 많음.
**유닛이코노믹스**: CPM 기반, **트래픽 볼륨에 비례** → 초기 소규모엔 미미, 스케일나면 안정적 baseline. 마진 높음.
**리스크**: UX 훼손(과하면 이탈), 볼륨 필요, 광고 SDK 의존.
**검증 실험**: 결과 화면에 **리워드 광고 1개**만 붙여 — 해금률·이탈률 측정. (전면광고는 이탈 크니 나중)

## 2. ⭐ 스폰서/브랜디드 콘텐츠 (차별화 엔진)
**작동**: 브랜드가 **통 1개(브랜디드 테스트)** 또는 **카드뉴스**를 스폰서. 예) "○○화장품 X 나의 퍼스널컬러 테스트", 결과에 브랜드 메시지/링크. **광고인데 유저가 공유하고 싶어하는 콘텐츠.**
**타깃 적합성**: 자기발견+공유 포맷이 캠페인과 천생연분. 봉봉/테스트 플랫폼의 실제 주 수익원이 이거.
**유닛이코노믹스**: 건당 캠페인 단가(수백만원~) → **마진·단가 최고**. 단 **영업(B2B) + 오디언스 규모** 필요.
**리스크**: 오디언스 없으면 못 팖(닭-달걀), 영업 리소스, 스폰서 표기 신뢰.
**검증 실험**: 유저 N만 모인 뒤 **브랜드 1곳 파일럿**(무료/저가로 한 캠페인) → 참여·공유·클릭 리포트로 세일즈 자료화.

## 3. 운세/심층결과 IAP · 프리미엄 (근거리 현금)
**작동**: 무료는 요약 결과, **심층 리포트·프리미엄 운세(사주/타로)·광고 제거**는 유료(IAP 단건 or 월구독). 운세는 데일리 구독 친화.
**타깃 적합성**: **국내 운세 WTP가 실재적** — 포스텔러/점신이 심층 유료로 잘 범. 자기발견 깊이 원하는 층.
**유닛이코노믹스**: 전환율 보통 1~5%, 운세 버티컬은 더 높을 수 있음. ARPPU는 콘텐츠 깊이에 비례.
**리스크**: 무료 결과가 충분하면 전환 안 됨 → 프리미엄 가치 설계가 관건. 페이월 반발.
**검증 실험**: 운세 통 1개에 **"심층 보기 ₩2,900" 페이월** → 결제 전환율 측정. 가격 A/B.

## 4. 창작자 마켓플레이스 / 정산 (장기)
**작동**: 외부 창작자가 통·카드뉴스 올리고, 그 콘텐츠가 만든 광고/스폰서 수익을 **레브셰어**(플랫폼이 take rate). 또는 프리미엄 창작 콘텐츠.
**타깃 적합성**: 콘텐츠 공급 네트워크효과 → 공급↑가 수요↑. 단 생태계 성숙 필요.
**유닛이코노믹스**: take rate 10~30%. 공급·수요 양면 유동성이 전제.
**리스크**: 닭-달걀(공급), 품질·신뢰·정산 복잡도. **near-term 아님.**
**검증 실험**: 소수 창작자 초대 → 공급 의지·콘텐츠 품질 확인 (수익화 전 단계).

---

## 단계별 로드맵

| 단계 | 목표 | 수익화 |
|---|---|---|
| **런칭 초기** | 유저·콘텐츠·바이럴 확보 | **수익화 거의 OFF** (리워드 광고만 가볍게 테스트) |
| **성장** | DAU·공유·리텐션 증명 | 운세/심층결과 **IAP** + 리워드 광고 + **스폰서 파일럿 1건** |
| **성숙** | 오디언스 세일즈 가능 | **스폰서/브랜디드 본격**(주 수익) + 구독 + 네이티브 광고 |
| **확장** | 창작자 생태계 | 마켓플레이스 **레브셰어** |

→ **테스트 1순위**: ① 리워드 광고(결과 해금) ② 운세 심층결과 페이월. 둘 다 **소규모로 즉시 검증 가능**.

## ⭐ 지금 제품에 심어둘 훅 (수익화-레디 설계)

나중에 수익화를 **앱 재배포 없이/적은 변경으로** 붙이려면 지금 데이터·구조에 자리를 비워둬:

| 훅 | 무엇 | 비용 |
|---|---|---|
| **결과 화면 = 수익화 슬롯** | 통 결과 화면을 [공유카드 + 리워드광고 + 프리미엄 업셀 + 제휴링크] 꽂을 수 있게 설계 | 웹 번들/네이티브 결과 표면 규약 |
| **스폰서 플래그** | `Tong`/`CardNews`에 `is_sponsored`, `sponsor_name`, `sponsor_meta` (지금 컬럼만 비워둠) + SDUI "스폰서" 뱃지 | 컬럼 몇 개 (저렴) |
| **광고 슬롯 섹션 타입** | SDUI에 `ad_slot`/`banner` 섹션 예약 → 나중에 **서버드리븐으로 광고 위치 조정**(재배포 X) | 섹션 카탈로그에 1개 |
| **엔타이틀먼트/프리미엄** | `User.is_premium` + 콘텐츠 `is_premium`/페이월 개념 최소 골격 | 플래그 2개 |
| **이벤트 추적** | 노출·완독·공유·결과도달 이벤트 → **광고/스폰서 세일즈엔 오디언스 지표가 필수** + 페이월 가격 근거 | 추적 파이프(공유/조회수 과제와 연계) |
| **카테고리 타게팅** | 이미 카테고리 있음 → 광고 타게팅·스폰서 매칭에 재활용 | 0 (이미 있음) |

> 핵심: **결과 화면**과 **콘텐츠 메타(스폰서/프리미엄 플래그)**, **이벤트 추적** 셋이 수익화의 3대 토대. 지금 cheap하게 자리만 잡아두면 Phase 2에서 빠르게 붙는다.

## 리스크 총평
- 가장 큰 리스크는 **"오디언스 없이 수익화 서두르기"** → UX 망치고 바이럴 죽음. **유저 먼저** 원칙 유지.
- 광고는 baseline일 뿐, **진짜 마진은 스폰서/IAP**. 광고만 보고 가면 박리다매.
- 운세 IAP는 **국내에서 검증된 현금흐름**이라 근거리 실험 가치 높음.
