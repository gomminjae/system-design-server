**작성일**: 2026-06-30 · **상태**: 확정(편집 가능). 관련 [`personalization-design.md`]

---

## 0. 확정 결정

- **이름**: `Cosmi` / `코스미` (cosmos + i = "내 작은 우주"). 유닛 별도명 없음(코드는 tong).
- **컨셉**: **너는 하나의 우주.** 운세·사주·타로·심리테스트 = 네 우주의 별들.
- **포지셔닝**: "운세를 짤처럼." 1분짜리 자기발견 엔터.
- **메인 태그라인**: **너의 우주를 펼쳐봐.**
- **보이스**: 친구처럼 반말 + 위트(점쟁이 말투 금지).
- **무드**: 다크 스페이스 + 아우라/성운 그라데이션 + 별·궤도 모티프.

## 2. 워드마크

- `cosmi` / `코스미` — 굵은 지오메트릭 산세.
- 모티프 **별·궤도·성운 라인** (점→점 잇는 별자리 선) — 그래픽 요소로 반복.
- 단색(text) 또는 primary 그라데이션 2종. `i`의 점을 별/행성으로 표현.

## 4. 이목 장치 (실행)

1. **우주 카드(OG)** — "내 우주 = OO" 공유 카드 → 카톡/IG 확산(바이럴 1순위)
2. **성운 누적** — 프로필이 *내 별/색 성운*으로 자라남(수집욕·재방문)
3. **밈 톤 카피** — 결과/푸시가 짤처럼 캡처됨
4. **데일리 우주** — "오늘의 너"(앱 단계)

## 5. 적용 순서

1. 위 **컬러/워드마크 토큰** → 통(tong) 표준 템플릿 `theme.css` + 앱 theme에 주입(통일)
2. **우주 카드 OG** 디자인·`/share` 엔드포인트
3. **카피 가이드** 반영(앱 곳곳·푸시)
